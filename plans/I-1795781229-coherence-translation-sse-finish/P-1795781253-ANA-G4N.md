     - In `_build_gemini_candidate_chunk`, replace the divergent 4-line ternary:
       ```python

           cand["finishReason"] = _map_finish_reason(finish_reason)
       ```
       This removes the streaming bug where non-`"stop"`/non-`"tool_calls"` reasons defaulted to `"MAX_TOKENS"` while non-streaming defaulted to `"STOP"`, and saves 2 lines.
   - **Add incomplete-line carry buffer in `stream_state` inside `translate_openai_sse_chunk_to_gemini`**:
     - Update signature to:
       ```python
       def translate_openai_sse_chunk_to_gemini(
           chunk_str: str,
           stream_state: dict[str, Any] | None = None,
           *,
           flush: bool = False,
       ) -> str:
       ```
     - When `stream_state is not None`:
       - Prepend any carried partial line: `combined = stream_state.pop("line_buffer", "") + chunk_str`
       - If `flush`:
         - `lines = combined.split("\n")` (drains any trailing non-newline-terminated line; `line_buffer` remains cleared so repeated flushes are idempotent).
       - Else:
         - `lines = combined.split("\n")`
         - `stream_state["line_buffer"] = lines.pop()` (when `combined` ends in `\n`, `lines.pop()` is `""`; when `combined` ends mid-line, the incomplete trailing fragment is carried in `stream_state["line_buffer"]` until the next call or EOF flush).
     - When `stream_state is None`:
       - `lines = chunk_str.split("\n")` (preserves backward compatibility for stateless single-chunk callers).
     - Iterate over `lines` and process each stripped `SSE_DATA_PREFIX` line as before.
   - **Maintain line count strictly `<= 442` without modifying `holon-config/hygiene/module_budgets.json`**:
     - In `_flush_buffered_tool_calls`, replace the duplicated `try/except Exception` JSON parsing block with `b_args = _parse_func_args(b_args_raw) if b_args_raw else {}` (saves 3 lines and reduces broad-except count by 1).
     - Compact multi-line dict literals in `_process_content_part`, `_translate_tool_responses`, or `translate_openai_to_gemini_response` only as needed so the final formatted file (`uv run ruff format .`) is strictly `<= 442` lines (target ~432–438 lines).

     - Pass `flush=flush` to `translate_openai_sse_chunk_to_gemini(text, stream_state=getattr(flow, "_sse_stream_state", None), flush=flush)`.

       - `decoded = utf8_decoder.decode(chunk, final=False)`

     - On EOF (`chunk == b""`) when `is_gemini_bridged`:

   - Keep non-bridged passthrough, timing fields (`first_chunk_time`, `last_chunk_time`), `_MAX_SSE_BUFFER_BYTES` capping, and `existing_stream` chaining unchanged.
