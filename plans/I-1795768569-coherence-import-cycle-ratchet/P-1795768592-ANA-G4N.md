### Implementation Details

Create `tests/test_import_cycle_ratchet.py` with strictly **zero docstrings** and **zero comments**, explicit Python 3.13 type annotations, and small single-responsibility helpers that stay well under Ruff's complexity limits (`C901 <= 10`, `PLR0912 <= 12`, `PLR0915 <= 50`):

- Constants:
  - `REPO_ROOT = Path(__file__).resolve().parent.parent`
  - `PACKAGE_ROOT = REPO_ROOT / "src" / "holon_coherence"`
  - `PACKAGE_NAME = "holon_coherence"`
  - `BASELINE_CYCLE_EDGES: dict[tuple[str, str], int]` locked to the verified live counts:
    ```python
    BASELINE_CYCLE_EDGES: dict[tuple[str, str], int] = {
        ("commands", "container"): 4,
        ("container", "commands"): 3,
        ("parsers", "providers"): 3,
        ("providers", "parsers"): 4,
    }
    ```
- Helper functions:
  - `discover_subpackages(package_root: Path) -> frozenset[str]`: returns names of direct subdirectories containing `__init__.py`.
  - `_resolve_import_from_targets(node: ast.ImportFrom, pkg_parts: list[str], package_name: str) -> list[str]`: handles both absolute (`level == 0`: `from holon_coherence.x...` and `from holon_coherence import x`) and relative (`level > 0`: `from ..x import ...` and `from .. import x`) imports cleanly.
  - `_extract_imported_subpackages(tree: ast.AST, pkg_parts: list[str], package_name: str) -> list[str]`: walks `ast.walk(tree)` so both top-level and function-local imports are captured, extracting `ast.Import` (`import holon_coherence.x...`) and `ast.ImportFrom` targets.
  - `collect_subpackage_edges(package_root: Path, package_name: str = PACKAGE_NAME) -> dict[tuple[str, str], int]`: iterates sorted `package_root.rglob("*.py")`, skips modules not inside a top-level subpackage, counts every cross-subpackage import reference where `target in subpackages and target != src_pkg`, and returns a sorted `dict[tuple[str, str], int]`.
  - `_is_reachable(adjacency: dict[str, set[str]], start: str, goal: str) -> bool`: iterative BFS/DFS checking if `goal` is reachable from `start`.
  - `find_cyclic_edges(edges: dict[tuple[str, str], int]) -> dict[tuple[str, str], int]`: builds directed adjacency sets from `edges` and keeps every edge `(src, dst)` where `_is_reachable(adjacency, dst, src)` is `True`. This captures both 2-node mutual cycles and any N-node cycle (`A -> B -> C -> A`).
  - `find_cycle_regressions(observed_cyclic_edges: dict[tuple[str, str], int], baseline: dict[tuple[str, str], int]) -> list[str]`:
    - For each `(src, dst), count` in `sorted(observed_cyclic_edges.items())`:
      - If `(src, dst) not in baseline`: append a clear regression message naming the new cyclic edge and count.
      - Else if `count > baseline[(src, dst)]`: append a clear regression message naming the edge, baseline count, and observed count.
    - Equal or lower counts (including missing/broken cycles) produce zero regressions so cycle-breaking changes pass cleanly.
- Live repository ratchet test:
  - `test_live_subpackage_import_cycle_ratchet() -> None`: scans `PACKAGE_ROOT`, computes `find_cyclic_edges(collect_subpackage_edges(PACKAGE_ROOT))`, asserts `find_cycle_regressions(observed, BASELINE_CYCLE_EDGES) == []` with a readable multi-line failure message.
