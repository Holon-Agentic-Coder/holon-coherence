   - Count lines deterministically via `len(path.read_text(encoding="utf-8").splitlines())`.
   - For each discovered module:
     - Determine `budget = overrides.get(rel_path, default_max_lines)`.
     - If `line_count > budget`: append an error (`f"{rel_path}: {line_count} lines exceeds budget of {budget} lines"`).
     - Else if `rel_path in overrides` and `line_count < budget`:
       - If `line_count <= default_max_lines`: append a ratchet-down notice instructing removal of the override (`f"RATCHET-DOWN: {rel_path} shrunk to {line_count} lines (<= {default_max_lines}); remove override from module_budgets.json"`).
       - Else: append a ratchet-down notice instructing tightening the override (`f"RATCHET-DOWN: {rel_path} shrunk from {budget} to {line_count} lines; lower override in module_budgets.json"`).
   - For each key in `overrides` not present among discovered modules (and not excluded): emit a stale-override notice or error if the file no longer exists on disk.
5. **Frozen-config verification against merge base (`resolve_merge_base`, `load_config_at_ref`, `verify_frozen_config`):**
   - Resolve merge base via `git merge-base HEAD <base_ref>` (trying `--base-ref` if provided, otherwise probing `origin/main` then `main`).
   - Load `<merge_base>:holon-config/hygiene/module_budgets.json` via `git show`. If the repo has no merge base or the config file did not exist at the merge base (e.g., on the initial introducing PR), skip merge-base comparison cleanly unless `--require-base` is passed.
   - When base config is present, enforce ratchet-down-only invariants:
     - `current["default_max_lines"] > base["default_max_lines"]` -> error.
     - Any key in `current["overrides"]` not in `base["overrides"]` -> error (no new overrides allowed).
     - Any key in both `overrides` where `current["overrides"][k] > base["overrides"][k]` -> error (overrides may only stay equal or decrease).
     - Any newly added `exclude` entry relative to `base["exclude"]` must have a non-empty `"reason"` (already enforced by schema validation; optionally flag if excluding an existing tracked `src/`/`scripts/` module).
6. **CLI entrypoint (`main(argv: list[str] | None = None) -> int`):**
   - Support `--repo-root <path>`, `--config <path>`, `--base-ref <ref>`, `--no-merge-base`, and `--require-base` flags via `argparse` for both CI/local execution and hermetic testing.

$$\text{EV} = P(\text{success}) \times \text{Impact} + \mu \times \text{LearningValue} - \lambda \times \Delta S_{\text{intent}} - \text{Cost}$$
