### Implementation Details

Update `src/holon_coherence/proxy/steps/serve_dashboard.py` (zero docstrings, zero comments, `<= 200` lines, full type annotations):

1. **Imports & constants:**
   - Standard library: `hmac`, `json`, `os`, `from pathlib import Path`, `from typing import Any`, `from urllib.parse import urlparse`.
   - `_LOOPBACK_HOSTS = frozenset({"127.0.0.1", "localhost", "::1"})`
   - `_METRICS_PATHS = ("/holon/api/metrics", "/_holon/metrics")`
   - `_MODE_PATHS = ("/holon/api/mode", "/_holon/mode")`
   - `_JSON_HEADERS = {"Content-Type": "application/json"}`
2. **Header lookup helper `_get_header(flow: Any, name: str) -> str`:**
   - Read `headers = getattr(flow.request, "headers", None) or {}`.
   - Perform case-insensitive lookup (`for k, v in headers.items(): if str(k).lower() == target: return str(v)`), returning `""` if absent.
3. **Loopback host validation:**
   - `_is_loopback_host(raw_host: str) -> bool`:
     - `host = raw_host.strip().lower()`
     - If not `host` or any char in `host` is whitespace or in `("/", "\\", "@", "?", "#")`: return `False`.
     - If `host in ("::1", "[::1]")`: return `True`.
     - Parse `parsed = urlparse(f"http://{host}")` (wrapping `ValueError` -> `False`), ensure `parsed.hostname in _LOOPBACK_HOSTS` and `parsed.username is None` and `parsed.password is None`.
   - `_is_loopback_request(ctx: RequestContext) -> bool`:
     - `host_header = _get_header(ctx.flow, "host").strip()`
     - If `host_header`: return `_is_loopback_host(host_header)`.
     - Fallback when `Host` header is absent/empty: parse `ctx.url` via `urlparse(ctx.url if "://" in ctx.url else f"http://{ctx.url}").hostname or ""` (or `getattr(ctx.flow.request, "host", "")` if `ctx.url` is empty) and check `_is_loopback_host(url_host)`.
   - Gate `serve_metrics`, `serve_mode`, `serve_html`, and `serve_dashboard`:
     - Each handler returns `Outcome.CONTINUE` immediately if `not _is_loopback_request(ctx)`.
     - This ensures `/holon`, `/holon/*`, and `/_holon/*` requests targeting external `Host` headers pass through untouched (`flow.response` stays `None`).
4. **Remove wildcard CORS in `serve_metrics`:**
   - Pass `_JSON_HEADERS` (`{"Content-Type": "application/json"}`) to `_make_http_response`; never emit `Access-Control-Allow-Origin: *`.
5. **Origin validation (403) and Bearer token auth (401) on mode POST:**
   - `_is_loopback_origin(origin: str) -> bool`:
     - Parse `parsed = urlparse(origin.strip())` (catching `ValueError` -> `False`).
     - Require `parsed.scheme in ("http", "https")` and `(parsed.hostname or "").lower() in _LOOPBACK_HOSTS` and `parsed.username is None` and `parsed.password is None`.
   - `_expected_api_token() -> str`:
     - Return `(os.getenv("HOLON_COHERENCE_API_TOKEN") or os.getenv("HOLON_COHERENCE_WEB_PASSWORD") or "").strip()`.
   - `_is_authorized_bearer(flow: Any) -> bool`:
     - `expected = _expected_api_token()`
     - If not `expected`: return `False` (fail closed).
     - `auth = _get_header(flow, "authorization").strip()`
     - `scheme, _, provided = auth.partition(" ")`
     - If `scheme.lower() != "bearer"` or not `provided.strip()`: return `False`.
     - Return `hmac.compare_digest(provided.strip(), expected)`.
   - In `_mode_post(ctx)`:
     - Check `origin = _get_header(flow, "origin").strip()`; if `origin` and not `_is_loopback_origin(origin)`: respond `403` with `{"error": "Forbidden origin"}` and return.
     - If not `_is_authorized_bearer(flow)`: respond `401` with `{"error": "Unauthorized"}` and return.
6. **Confine `wire_log_dir` on mode POST (400):**
   - `_allowed_wire_log_base(addon: Any) -> Path`:
     - `env_base = (os.getenv("HOLON_WIRE_LOG_BASE_DIR") or "").strip()`
     - If `env_base`: return `Path(os.path.expanduser(env_base)).resolve()`.
     - `initial = getattr(addon, "_base_wire_log_dir", None)`
     - If `initial is None`: `initial = addon.wire_log_dir`; `addon._base_wire_log_dir = initial`.
     - Return `Path(os.path.expanduser(str(initial))).resolve()`.
   - `_resolve_confined_wire_log_dir(addon: Any, raw_dir: Any) -> str`:
     - If `not isinstance(raw_dir, str)` or not `raw_dir.strip()` or `"\x00" in raw_dir`: raise `ValueError("Invalid wire_log_dir")`.
     - `base = _allowed_wire_log_base(addon)`
     - `candidate = (base / os.path.expanduser(raw_dir.strip())).resolve()`
     - If `not candidate.is_relative_to(base)`: raise `ValueError("wire_log_dir outside allowed base directory")`.
     - Return `str(candidate)`.
   - In `_mode_post(ctx)`:
     - Parse JSON body and validate `isinstance(mode_data, dict)` (else raise `ValueError("Invalid JSON object")`).
     - Validate `wire_log_dir` (if provided and truthy) via `_resolve_confined_wire_log_dir` BEFORE mutating `addon.default_passive` or `addon.wire_log_dir`.
     - Apply `addon.default_passive` and `addon.wire_log_dir` updates only after all validations succeed.
     - Return `200` JSON response with `status`, `mode`, `wire_log_dir`; on any `ValueError`/`json.JSONDecodeError`/`OSError`, return `400` JSON error.
7. **Fix `_mode_get` precedence:**
   - `default_passive = getattr(addon, "default_passive", None)`
   - `is_passive = default_passive if isinstance(default_passive, bool) else is_passive_monitoring()`
   - `current_mode = "baseline" if is_passive else "optimized"`
