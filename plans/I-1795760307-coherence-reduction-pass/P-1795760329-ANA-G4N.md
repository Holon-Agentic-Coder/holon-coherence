### Implementation Details

Create `src/holon_coherence/reduction_passes.py` (target ~100–130 lines, strictly `<= 200` lines, zero docstrings, zero disallowed comments, `from __future__ import annotations`):

1. **`ReductionContext` dataclass**:
   - Fields:
     - `cleaner: JSONContextCleaner` (imported under `TYPE_CHECKING` to avoid circular imports at runtime)
     - `provider: str`
     - `seen_content_hashes: dict[str, tuple[int, str]]`
     - `stats: dict[str, int]`
   - Expose read-only convenience properties delegating to `self.cleaner` settings (`enable_deduplication: bool`, `enable_prompt_caching: bool`, `max_turns: int`, `recent_turns_to_keep: int`) so custom passes can read cleaner settings directly from `context` without reaching into private internals, while still providing direct access to `context.cleaner`.
2. **`ReductionPass` structural Protocol (`@runtime_checkable`)**:
   - `@property def name(self) -> str: ...` (note: a plain `name: str` attribute on implementing classes also satisfies `@runtime_checkable` `isinstance` checks in Python 3.13; declaring `name: str` or `@property def name(self) -> str: ...` works with both attributes and properties—prefer `@property def name(self) -> str: ...` or `name: str` and verify both attribute-based and property-based implementations pass `isinstance(obj, ReductionPass)` in tests).
   - `def applies(self, provider: str, payload: dict[str, Any]) -> bool: ...`
   - `def apply(self, payload: dict[str, Any], context: ReductionContext) -> dict[str, Any]: ...`
3. **`ProviderCleanPass`**:
   - Built-in pass with `name: str = "provider_clean"`.
   - `applies(self, provider: str, payload: dict[str, Any]) -> bool` returns `True`.
   - `apply(self, payload: dict[str, Any], context: ReductionContext) -> dict[str, Any]` resolves `get_provider(context.provider)` and returns `provider_format.clean(context.cleaner, payload, context.seen_content_hashes, stats=context.stats)`.
4. **`ReductionPassRegistry`**:
   - Maintains deterministic insertion order via an internal `dict[str, ReductionPass]` (`self._passes: dict[str, ReductionPass] = {}`).
   - `__init__(self, passes: Iterable[ReductionPass] | None = None) -> None` registers initial passes in order.
   - `register(self, reduction_pass: ReductionPass, *, replace: bool = False) -> None`:
     - Validates `isinstance(reduction_pass, ReductionPass)` (raising `TypeError` otherwise) and non-empty `reduction_pass.name` (raising `ValueError` otherwise).
     - Raises `ValueError` on duplicate name unless `replace=True`, preserving deterministic ordering.
   - `unregister(self, name: str) -> ReductionPass | None`: removes and returns the pass by name (or `None`).
   - `get(self, name: str) -> ReductionPass | None`: looks up a pass by name.
   - `names(self) -> tuple[str, ...]`: returns pass names in deterministic execution order.
   - `__iter__(self) -> Iterator[ReductionPass]` and `__len__(self) -> int` for deterministic iteration and sizing.
   - `iter_active(self, enabled_passes: Collection[str] | None = None, disabled_passes: Collection[str] | None = None) -> Iterator[ReductionPass]`:
     - Yields registered passes in deterministic insertion order, filtered by:
       - If `enabled_passes is not None`: only yield passes with `p.name in enabled_passes`.
       - If `disabled_passes is not None`: skip passes with `p.name in disabled_passes`.
   - `run(self, payload: dict[str, Any], context: ReductionContext, *, enabled_passes: Collection[str] | None = None, disabled_passes: Collection[str] | None = None) -> dict[str, Any]`:
     - Iterates over `self.iter_active(enabled_passes=enabled_passes, disabled_passes=disabled_passes)`.
     - For each pass, if `reduction_pass.applies(context.provider, current_payload)` is truthy, updates `current_payload = reduction_pass.apply(current_payload, context)`.
     - Returns `current_payload`.
5. **`default_pass_registry() -> ReductionPassRegistry`**:
   - Factory returning `ReductionPassRegistry((ProviderCleanPass(),))`.
