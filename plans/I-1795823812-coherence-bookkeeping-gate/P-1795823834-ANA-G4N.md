## Step 2: Implement fail-closed gate logic and CLI in `scripts/ci_bookkeeping_gate.py`

### Step Intent & Git Integration

- **Sub-intent recommendation:** none (inline step)
- **Reasoning:** Encapsulates all fail-closed policy rules, path allowlist checks, label checks, ancestor check-run chain traversal, and `GITHUB_OUTPUT` writing in a clean, testable CLI module under 200 lines.
- **Step type:** implementation
- **Exploration level:** none
- **Git branch:** same feature branch

### Implementation Details

Create `scripts/ci_bookkeeping_gate.py` (~140–175 lines, strictly `< 200`, Python 3.13 stdlib only, zero docstrings, zero comments):

1. Import sibling API module using the repository's dual-mode import pattern:
   ```python
   try:
       from scripts.ci_bookkeeping_api import CheckRunInfo, CommitInfo, CompareResult, GitHubApiError, GitHubBookkeepingClient
   except ModuleNotFoundError:
       from ci_bookkeeping_api import CheckRunInfo, CommitInfo, CompareResult, GitHubApiError, GitHubBookkeepingClient
   ```
2. Define policy constants:
   - `ALLOWED_PREFIXES = ("plans/", "executions/", "holon-knowledge/")`
   - `ALLOWED_SUFFIXES = (".md", ".json", ".jsonl")`
   - `RESULT_AFFECTING_LABELS = frozenset({"module-budget-change", "ci-timing-override", "timing-regression-accepted"})`
   - `MAX_COMPARE_FILES = 300`
   - `MAX_CHAIN_DEPTH = 20`
3. Define `GateDecision(skip: bool, reason: str)` frozen dataclass.
4. Implement pure path validation helpers:
   - `is_bookkeeping_path(path: str) -> bool`: reject empty paths, leading `/`, `\\`, or any `..` path segment; require `path.startswith(ALLOWED_PREFIXES)` and `PurePosixPath(path).suffix in ALLOWED_SUFFIXES`.
   - `all_bookkeeping_files(files: tuple[tuple[str, str | None], ...]) -> bool`: return `False` if `files` is empty or `len(files) >= MAX_COMPARE_FILES`; return `True` only when every `filename` and every non-empty `previous_filename` satisfies `is_bookkeeping_path`.
5. Implement check-run and chain verification:
   - `_has_green_check(runs: tuple[CheckRunInfo, ...], check_name: str) -> bool`: return `True` if any run matches `run.name == check_name` with `run.status == "completed"` and `run.conclusion == "success"`.
   - `verify_green_ancestor_chain(client: Any, start_sha: str, check_name: str, max_depth: int = MAX_CHAIN_DEPTH) -> GateDecision`:
     - Walk up to `max_depth` commits starting from `start_sha`, tracking `visited` SHAs to guard against cycles.
     - At each `sha`:
       - Verify `_has_green_check(client.list_check_runs(sha, check_name), check_name)`; if `False`, return `GateDecision(False, f"no green check-run for {check_name} on {sha[:12]}")`.
       - Fetch `commit = client.get_commit(sha)`.
       - If `not all_bookkeeping_files(commit.files)`: this ancestor is a real code commit whose check-run succeeded cleanly -> return `GateDecision(True, f"verified green ancestor {sha[:12]}")`.
       - Otherwise (`sha` was itself a bookkeeping-only commit that may have been skipped): require `len(commit.parents) == 1` (fail closed on merge or root commits) and advance `sha = commit.parents[0]`.
     - If loop exhausts `max_depth`, fail closed with `GateDecision(False, "ancestor chain exceeded max depth")`.
6. Implement `evaluate_gate(event: Mapping[str, Any], env: Mapping[str, str], client: Any, check_name: str) -> GateDecision`:
   - Require `env.get("GITHUB_EVENT_NAME") == "pull_request"`.
   - Require `env.get("GITHUB_RUN_ATTEMPT", "1") == "1"` (never skip manual re-runs).
   - Require non-empty `check_name`.
   - Dispatch on `action = event.get("action")`:
     - If `action in {"labeled", "unlabeled"}`:
       - Extract `label_name = (event.get("label") or {}).get("name", "")`.
       - If not `label_name` or `label_name in RESULT_AFFECTING_LABELS`: return `GateDecision(False, f"result-affecting label: {label_name or 'unknown'}")`.
       - Extract `head_sha = ((event.get("pull_request") or {}).get("head") or {}).get("sha", "")`; fail closed if missing.
       - Return `verify_green_ancestor_chain(client, head_sha, check_name)`.
     - If `action == "synchronize"`:
       - Extract `before = event.get("before", "")` and `after = event.get("after", "")`; fail closed if missing or identical.
       - Compare `before...after` via `client.compare_commits(before, after)`.
       - Require `compare.status == "ahead"` (fail closed on `diverged`, `behind`, `identical`, or unknown).
       - Require `all_bookkeeping_files(compare.files)` (fail closed on any non-bookkeeping path, rename crossing boundary, empty diff, or `>= 300` files).
       - Return `verify_green_ancestor_chain(client, before, check_name)`.
     - Any other `action` (`opened`, `reopened`, `edited`, etc.): return `GateDecision(False, f"unsupported pull_request action: {action}")`.
   - Wrap API calls in `try ... except GitHubApiError as exc:` returning `GateDecision(False, f"github api error: {exc}")`.
7. Implement `main(argv: list[str] | None = None, env: Mapping[str, str] = os.environ) -> int`:
   - Parse `--check-name` (required) and optional `--event-path`.
   - Load event JSON from `--event-path` or `env["GITHUB_EVENT_PATH"]`; fail closed on missing/unreadable/invalid JSON, missing `GITHUB_TOKEN`, or missing `GITHUB_REPOSITORY`.
   - Construct `GitHubBookkeepingClient`, evaluate `evaluate_gate(...)`, write `skip=true`/`skip=false` and single-line `reason=...` to `env["GITHUB_OUTPUT"]` when set, print a `::notice::` summary line, and always exit `0` (gate never breaks CI; it only outputs `skip=true` or `skip=false`).
