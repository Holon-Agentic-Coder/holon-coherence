## Step 2: Implement `scripts/check_commit_trailers.py` and register in self-doc scope

### Step Intent & Git Integration

### Implementation Details

Create `scripts/check_commit_trailers.py` (target ~80–110 lines, well below the 200-line `default_max_lines` budget):

- First line must be `#!/usr/bin/env python3`, followed by `from __future__ import annotations`.
- Zero docstrings and zero comments (satisfies both the intent's self-explaining code invariant and `tests/test_repo_self_doc.py` / `tests/test_scripts_self_doc.py`).
- Constants:
  - `FORBIDDEN_PREFIXES: tuple[str, ...] = ("co-authored-by", "co-developed-by", "generated-by", "assisted-by", "generated with [claude code")`
- Pure function `find_attribution_lines(message: str) -> list[str]`:
  - Iterates over `message.splitlines()`.
  - Computes `stripped = line.lstrip()`.
  - Skips lines where `stripped.startswith("#")`.
  - Checks `stripped.lower().startswith(FORBIDDEN_PREFIXES)`.
  - Appends offending `line` (or `stripped`) to the returned list.
- Helper `check_message_file(path: Path) -> int`:
  - Reads `path.read_text(encoding="utf-8", errors="replace")`.
  - Calls `find_attribution_lines(content)`.
  - For each offending line, writes `f"{path}: {offending_line}\n"` to `sys.stderr`.
  - Returns `1` if any offences exist, else `0`.
- Helper `check_revision_range(rev_range: str, repo_dir: Path | None = None) -> int`:
  - Runs `git rev-list <rev_range>` via `subprocess.run(..., capture_output=True, text=True, cwd=repo_dir)`.
  - If `returncode != 0`, writes git's stderr to `sys.stderr` and returns `2`.
  - For each commit SHA in `rev-list` output:
    - Fetches the commit message via `git show -s --format=%B <sha>` and short SHA via `git rev-parse --short <sha>`.
    - Calls `find_attribution_lines(message)`.
    - For each offending line, writes `f"{short_sha}: {offending_line}\n"` to `sys.stderr`.
  - Returns `1` if any offences exist across the range, else `0`.
- CLI `main(argv: list[str] | None = None) -> int`:
  - Uses `argparse.ArgumentParser` with a required mutually exclusive group containing `--message-file` and `--range`.
  - Dispatches to `check_message_file(Path(args.message_file))` or `check_revision_range(args.range)`.
  - Guarded by `if __name__ == "__main__": sys.exit(main())`.
- Update `tests/test_scripts_self_doc.py` to add `"scripts/check_commit_trailers.py"` (and `"tests/test_check_commit_trailers.py"`) to `SCRIPTS_SELF_DOC_FILES` so `test_scripts_self_doc_scope_covers_all_scripts` passes.
