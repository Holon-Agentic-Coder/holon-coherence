### Implementation Details

Update `scripts/check_module_budgets.py` (currently 164 lines; target `<= 185` lines, strictly `<= 200` lines, zero docstrings, zero comments beyond the line-1 shebang):

1. Extract a small helper `_evaluate_active_module(rel_path: str, actual: int, default_limit: int, overrides: dict[str, int], fail_on_stale: bool) -> tuple[str | None, str | None]` (5 args, within Ruff `PLR0913`) to keep cyclomatic complexity (`C901`) and branch count (`PLR0912`) low:
   - `in_overrides = rel_path in overrides`
   - `limit = overrides[rel_path] if in_overrides else default_limit`
   - If `actual > limit`:
     - `kind = "frozen override exceeded" if in_overrides else f"exceeds default budget of {default_limit}"`
     - Return `f"{rel_path}: {actual} > {limit} lines ({kind})"`, `None`
   - If `in_overrides and actual <= default_limit`:
     - `msg = f"Stale override notice: {rel_path} is {actual} lines (<= default {default_limit}); remove override"`
     - Return `(msg, None)` if `fail_on_stale` else `(None, msg)`
   - If `in_overrides and actual < limit`:
     - Return `None`, `f"Ratchet notice: {rel_path} shrunk to {actual} lines (< {limit}); lower override to {actual}"`
   - Otherwise return `None, None`.
2. Update `evaluate_budgets(repo_root: Path, config: dict[str, Any], modules: list[str], fail_on_stale: bool = False) -> tuple[list[str], list[str]]`:
   - Compute `default_limit`, `overrides`, `active`, and `active_set` as before.
   - Loop over `active`, calling `_evaluate_active_module(...)` and appending any non-`None` error or notice.
   - Loop over `sorted(overrides)`: if `rel_path not in active_set`, append an error (not a notice!) to `errors`:
     `errors.append(f"Missing override target: {rel_path} is not an active source module; remove override")`.
   - Return `errors, notices`.
3. Update `check_repo_budgets(...)` to accept `fail_on_stale: bool = False` (5 args total, within Ruff `PLR0913`) and pass `fail_on_stale=fail_on_stale` to `evaluate_budgets(...)`.
4. Update `main(argv: list[str] | None = None) -> int`:
   - Add `parser.add_argument("--fail-on-stale-overrides", action="store_true")`.
   - Pass `fail_on_stale=args.fail_on_stale_overrides` to `check_repo_budgets(...)`.
