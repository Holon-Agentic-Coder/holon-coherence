2. Define constants:
   - `BOOKKEEPING_PREFIXES = ("plans/", "executions/", "holon-knowledge/")`
   - `BOOKKEEPING_EXTENSIONS = (".md", ".json", ".jsonl")`

   - `all_files_bookkeeping(files: Sequence[ChangedFile]) -> bool`: return `bool(files)` and for every `ChangedFile`, `is_bookkeeping_path(f.filename)` and (if `f.previous_filename` is set) `is_bookkeeping_path(f.previous_filename)`.
   - `_is_valid_sha(sha: object) -> bool`: 40-char lowercase/hex string, not `ZERO_SHA`.
   - `_job_matches(job: JobRun, job_name: str) -> bool`: match exact `job.name == job_name` (or prefix match when matrix suffixes apply, e.g., `job.name == job_name`). Make sure the workflow passes the exact job display name or matrix-aware target name (`job-name` input in `action.yml`) so matrix jobs (`unit (ubuntu-latest)` vs `unit (macos-latest)`, `make (ubuntu-latest)` vs `make (macos-latest)`) match strictly per OS/job!
5. Implement `_has_green_chain_ancestor(api: BookkeepingApi, start_sha: str, workflow: str, job_name: str) -> bool`:
   - Loop up to `MAX_CHAIN_DEPTH` steps starting at `sha = start_sha`, tracking `visited: set[str]`:
     - Fetch `jobs = api.jobs_for_sha(sha, workflow)` and filter matching completed jobs (`j.status == "completed"` and `_job_matches(j, job_name)`).
     - If any matching job has `j.conclusion == "success"` and `not j.skipped_by_gate`: return `True`.
     - If a matching job has `j.conclusion == "success"` and `j.skipped_by_gate`:
       - Fetch `parents = api.commit_parents(sha)`. Require `len(parents) == 1` (linear history; fail closed on merges/root commits).
       - Verify the diff from `parents[0]` to `sha` via `api.compare_commits(parents[0], sha)` has `status == "ahead"`, `len(files) < MAX_COMPARE_FILES`, and `all_files_bookkeeping(files)`.
       - Advance `sha = parents[0]` and continue.
     - Otherwise return `False`.
   - Return `False` if `MAX_CHAIN_DEPTH` is exhausted.
6. Implement `evaluate_gate(ctx: GateContext, api: BookkeepingApi) -> GateDecision`:
   - Fail closed unless `ctx.event_name == "pull_request"`, `ctx.run_attempt == "1"`, and `action in ALLOWED_PR_ACTIONS`.
   - If `action in {"labeled", "unlabeled"}`:
     - Extract `label_name = (ctx.event.get("label") or {}).get("name")`.
     - If not a non-empty `str` or `label_name in RESULT_AFFECTING_LABELS`: return `GateDecision(False, ...)`.

   - If `action == "synchronize"`:
     - Extract `before = ctx.event.get("before", "")` and `after = ctx.event.get("after") or (ctx.event.get("pull_request") or {}).get("head", {}).get("sha", "")`.
     - Validate both SHAs and `before != after`.
     - Call `diff = api.compare_commits(before, after)`.
     - Require `diff.status == "ahead"`, `0 < len(diff.files) < MAX_COMPARE_FILES`, and `all_files_bookkeeping(diff.files)`.
     - Verify `_has_green_chain_ancestor(api, before, ctx.workflow, ctx.job_name)`.
   - Wrap all API calls in `try ... except API_ERRORS as exc:` returning `GateDecision(False, f"api-error: {exc}")`.
7. Implement `write_github_output(decision: GateDecision, output_path: str) -> None` and `main(argv: list[str] | None = None, *, env: Mapping[str, str] = os.environ, api: BookkeepingApi | None = None) -> int`:
