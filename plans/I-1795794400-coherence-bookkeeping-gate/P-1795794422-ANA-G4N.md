### Implementation Details

Create `scripts/ci_bookkeeping_gate.py` (target `<= 175` lines, stdlib-only, zero docstrings, zero comments):

1. Define constants and decision dataclass:
   - `BOOKKEEPING_PREFIXES = ("plans/", "executions/", "holon-knowledge/")`
   - `BOOKKEEPING_SUFFIXES = (".md", ".json", ".jsonl")`
   - `RESULT_AFFECTING_LABELS = frozenset({"module-budget-change", "ci-timing-override", "timing-regression-accepted"})`
   - `ALLOWED_PR_ACTIONS = frozenset({"synchronize", "labeled", "unlabeled"})`
   - `GATE_STEP_NAME = "Bookkeeping gate"`
   - `CHECKOUT_STEP_PREFIX = "Checkout"`
   - `MAX_COMPARE_FILES = 300`
   - `MAX_CHAIN_DEPTH = 20`
   - `@dataclass(frozen=True) class GateDecision`: `skip: bool`, `reason: str`.
2. Implement pure path and diff validators:
   - `is_bookkeeping_path(path: str) -> bool`: reject empty strings, leading `/`, backslashes, or any `..` path segment (`".." in PurePosixPath(path).parts`); return `path.startswith(BOOKKEEPING_PREFIXES) and path.endswith(BOOKKEEPING_SUFFIXES)`.
   - `is_bookkeeping_compare(result: CompareResult) -> tuple[bool, str]`:
     - Require `result.status == "ahead"`, `result.ahead_by > 0`, `result.behind_by == 0` (fail closed on force-push, divergence, or identical).
     - Require `0 < len(result.files) < MAX_COMPARE_FILES` (fail closed on empty or potentially truncated GitHub compare responses).
     - For every `(filename, previous_filename)` in `result.files`: verify `is_bookkeeping_path(filename)` and, if `previous_filename` is not `None`, verify `is_bookkeeping_path(previous_filename)`.
3. Implement job outcome classification and ancestor chain traversal:
   - `classify_job(job: JobRecord) -> str`:
     - Returns `"none"` unless `job.status == "completed"` and `job.conclusion == "success"`.
     - Inspects `job.steps` (excluding GitHub's built-in `"Set up job"` and `"Complete job"` steps, `Checkout*`, and `GATE_STEP_NAME`):
       - If any remaining step has `conclusion == "success"`, returns `"passed"` (a real full green run).
       - If remaining steps exist and all of them have `conclusion == "skipped"` (and `GATE_STEP_NAME` succeeded), returns `"skipped"` (a previously bookkeeping-skipped green run).
       - Otherwise returns `"none"` (fail closed).
   - `job_status_on_sha(api: GateApi, wf_id: int, sha: str, job_name: str) -> str`:
     - Iterates over `api.runs_for_sha(wf_id, sha)` and finds matching `job.name == job_name`.
     - Prefer `"passed"` if any completed run for `sha` has `"passed"`; otherwise remember `"skipped"` if seen; else `"none"`.
   - `has_prior_green_chain(api: GateApi, wf_id: int, start_sha: str, job_name: str) -> tuple[bool, str]`:
     - Walks from `sha = start_sha` for up to `MAX_CHAIN_DEPTH` steps, tracking `visited: set[str]` to guard against cycles:
       - `status = job_status_on_sha(api, wf_id, sha, job_name)`
       - If `status == "passed"`: return `(True, f"prior green job verified at {sha[:7]}")`.
       - If `status != "skipped"`: return `(False, f"no prior green job at {sha[:7]}")`.
       - Fetch `parents = api.commit_parents(sha)`; if `len(parents) != 1`: return `(False, f"non-linear history at {sha[:7]}")`.
       - Verify `is_bookkeeping_compare(api.compare(parents[0], sha))`; if false, return `(False, ...)`.
       - Advance `sha = parents[0]`.
     - If loop exhausts `MAX_CHAIN_DEPTH`: return `(False, "chain depth limit exceeded")`.
4. Implement top-level decision function `evaluate(env: Mapping[str, str], event: Mapping[str, Any], api: GateApi) -> GateDecision`:
   - Check `env.get("GITHUB_EVENT_NAME") == "pull_request"` -> else `skip=False`.
   - Check `env.get("GITHUB_RUN_ATTEMPT") == "1"` -> else `skip=False` (re-runs always execute).
   - Check `action = event.get("action")` in `ALLOWED_PR_ACTIONS` -> else `skip=False`.
   - Resolve `job_name = env.get("BOOKKEEPING_JOB_NAME") or env.get("GITHUB_JOB", "")` and `run_id = env.get("GITHUB_RUN_ID", "")`; if either is empty, `skip=False`.
   - Fetch `wf_id = api.workflow_id(run_id)`.
   - If `action in {"labeled", "unlabeled"}`:
     - Extract `label_name = (event.get("label") or {}).get("name", "")`.
     - If not `label_name` or `label_name in RESULT_AFFECTING_LABELS`: return `GateDecision(False, ...)`.
     - Extract `head_sha = ((event.get("pull_request") or {}).get("head") or {}).get("sha", "")`; if empty, `skip=False`.
     - Verify `has_prior_green_chain(api, wf_id, head_sha, job_name)` -> return `GateDecision(ok, reason)`.
   - If `action == "synchronize"`:
     - Extract `before = event.get("before", "")` and `after = event.get("after", "")`; if empty or `before == after` or all-zero SHA, `skip=False`.
     - Verify `is_bookkeeping_compare(api.compare(before, after))`; if false, return `GateDecision(False, reason)`.
     - Verify `has_prior_green_chain(api, wf_id, before, job_name)` -> return `GateDecision(ok, reason)`.
5. Implement `write_github_output(decision: GateDecision, env: Mapping[str, str]) -> None` and `main(env: Mapping[str, str] | None = None, api: GateApi | None = None) -> int`:
   - Load event JSON from `env.get("GITHUB_EVENT_PATH", "")`.
   - Build `github_api(...)` if `api is None` (requiring non-empty `GITHUB_REPOSITORY` and `GITHUB_TOKEN`, else fail closed).
   - Wrap evaluation in `try ... except API_ERRORS as exc:` returning `GateDecision(False, f"fail-closed on error: {exc}")`.
   - Write `skip=true` / `skip=false` and `reason=<sanitized single-line reason>` to `GITHUB_OUTPUT` if set, print status line to stdout, and always return `0`.
