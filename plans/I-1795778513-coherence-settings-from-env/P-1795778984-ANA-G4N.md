     - `passive_monitoring: bool = False` (`HOLON_PASSIVE_MONITORING`)
     - `enable_wire_logging: bool = True` (`ENABLE_WIRE_LOGGING`)
     - `ca_cert: Path | None = None` (`HOLON_CA_CERT`)

     - `architect_model: str = DEFAULT_ARCHITECT_MODEL` (`HOLON_ARCHITECT_MODEL`)

     - `no_proxy: str | None = None` (`NO_PROXY`)
     - `no_proxy_lower: str | None = None` (`no_proxy`)
   - Implement `@classmethod def from_env(cls, environ: Mapping[str, str] | None = None) -> CoherenceSettings:` reading `env = os.environ if environ is None else environ` at call time so no environment value or `HOME` expansion is ever frozen at import time.
