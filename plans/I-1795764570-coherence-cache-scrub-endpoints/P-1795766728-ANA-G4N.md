1. **Secret & Header Scrubbing (`scrub_sensitive_data`):**
   - Import `scrub_headers, scrub_payload` from `holon_coherence.proxy.scrubbing`.
   - Define a compact top-level helper `scrub_sensitive_data(data: Any) -> Any` that runs `scrub_payload(data)` and, when
     a dict contains a `"headers"` mapping (or nested `"headers"` key in top-level dict/response), applies
     `scrub_headers` so header names in `_SECRET_HEADER_NAMES` (such as `x-api-key`, `cookie`, `set-cookie`,
     `x-anthropic-api-key`, `holon-agent-key`) are also redacted in addition to `_SECRET_DICT_KEY_PATTERN` and
     `_BODY_SECRET_PATTERNS`.
   - Apply `scrub_sensitive_data(payload)` inside `normalize_payload` before `json.dumps(...)` (so every normalized
     string, prefix key, stored `prompt_normalized`, and `user_tokens` is automatically scrubbed, and `get()` and `put()`
     produce identical prefix keys and shingles for payloads containing secrets).
   - Apply `scrub_sensitive_data(response)` in `put()` before `json.dumps(..., default=str)`.
2. **Restrictive Permissions (`0o700` dir, `0o600` SQLite DB and sidecars):**

   - Add a compact helper `_ensure_private_db_files(self) -> None`:
     - Pre-create `self.db_path` if missing using `os.open(self.db_path, os.O_CREAT | os.O_RDWR, 0o600)` and `os.close`.
     - Chmod `self.db_path`, `f"{self.db_path}-wal"`, and `f"{self.db_path}-shm"` (when present) to `0o600` with
       `contextlib.suppress(OSError)`.
   - Call `self._ensure_private_db_files()` before and after `_init_db()` (and after `put()` commits so WAL/SHM sidecars
     created on first write are also `0o600`).
3. **Drop Unused SQLite Index:**
   - In `_init_db()`, replace the 4-line `CREATE INDEX IF NOT EXISTS idx_prompt_cache_provider_system_created ...` with
     `cursor.execute("DROP INDEX IF EXISTS idx_prompt_cache_provider_system_created")`.
   - Keep `idx_prompt_cache_provider_created` (actively used by `_lookup_semantic_similarity_match`).
4. **Eliminate Redundant `normalize_payload` Calls in `put()` (and `get()`):**
   - Add a 2-line helper `_prefix_key_from_normalized(norm_prompt: str, provider: str) -> str` returning

   - Update `generate_prefix_key` to call `self._prefix_key_from_normalized(self.normalize_payload(payload, provider), provider)`.
   - In `put()`:
     - Call `norm_prompt = self.normalize_payload(payload, provider)` ONCE.
     - Compute `prefix_key = self._prefix_key_from_normalized(norm_prompt, provider)`.
     - Parse `normalized = self._parse_normalized(norm_prompt, payload)` (`json.loads(norm_prompt)` with fallback to
       `scrub_sensitive_data(payload)` on exception) — zero second or third `normalize_payload` call.
     - Extract `(user_content, system_prompt)` from `normalized`, compute `user_tokens` and `system_hash`, serialize
       `resp_json = json.dumps(scrub_sensitive_data(response), default=str)`, prune, and upsert.

     - Optionally pass the already-computed `norm_prompt` from `get()` into `_lookup_semantic_similarity_match` (or keep
       signature backward-compatible with an optional `norm_prompt: str | None = None`) so `get()` also normalizes only
