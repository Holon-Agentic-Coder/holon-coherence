### Implementation Details

- Create `scripts/check_ledger_rows_append_only.py` starting with `#!/usr/bin/env python3` and `from __future__ import annotations`, with zero docstrings and zero comments, and strictly <= 200 lines.
- Define `AppendOnlyCheckError(RuntimeError)` for unreadable git refs, missing repository, or git subprocess failures (CLI exit code `2`).
- Define `Violation` dataclass (`path: str`, `reason: str`, `row_index: int | None = None`).
- Implement importable functions:
  - `check_bytes_append_only(path: str, base_bytes: bytes, head_bytes: bytes | None) -> list[Violation]`:
    - If `head_bytes is None`, returns a violation indicating the base ledger/fragment file was deleted.
    - Splits `base_bytes` and `head_bytes` into raw line records (`splitlines()` on `bytes`, preserving exact row bytes without mutating encoding).
    - Checks that `len(head_rows) >= len(base_rows)` and for every index `i` in `range(len(base_rows))`, `head_rows[i] == base_rows[i]`.
    - Reports explicit violations when a base row was deleted (truncated), edited, or reordered (byte mismatch at `row_index = i + 1`).
    - Also verifies that if `base_bytes` is non-empty and did not end with `b"\n"` vs ended with `b"\n"`, the byte prefix before any appended rows matches identically (`head_bytes.startswith(base_bytes)` when `base_bytes.endswith(b"\n")`, or exact line-by-line byte equality when `base_bytes` had no trailing newline and a newline was added before appending).
  - `check_ledger_rows_append_only(repo: Path, base: str, head: str) -> list[Violation]`:
    - Verifies `repo.is_dir()` and resolves both `base` and `head` commits via `git rev-parse --verify <ref>^{commit}`; raises `AppendOnlyCheckError` immediately (fail closed) if either ref is unreadable.
    - Lists all `.jsonl` files under `holon-knowledge/ledger/` at `base` via `git ls-tree -r --name-only -z <base> -- holon-knowledge/ledger`.
    - For each `.jsonl` file present on `base`, reads raw bytes at `base` via `git show <base>:<path>` (raising `AppendOnlyCheckError` on git failure) and attempts to read raw bytes at `head` via `git show <head>:<path>` (treating missing-on-head as `head_bytes = None`, while unexpected git failures raise `AppendOnlyCheckError`).
    - Collects and returns all `Violation` records from `check_bytes_append_only`.
  - `main(argv: list[str] | None = None) -> int`:
    - Parses `--base` (required), `--head` (required), and `--repo` (default `"."`).
    - Prints each violation to stdout and returns `1` if any violations exist, `0` if clean, and `2` on `AppendOnlyCheckError` (printing error to stderr).
