2. **Helpers:**
   - `_completed_future() -> concurrent.futures.Future`: creates and returns a `Future` with `set_result(None)`.
   - `_wire_log_max_pending() -> int`: reads `os.getenv("WIRE_LOG_MAX_PENDING", "")`; if blank, returns
     `WIRE_LOG_MAX_PENDING`; otherwise parses `int(...)`, returning `WIRE_LOG_MAX_PENDING` on `ValueError` or values
     `< 0`.
   - `get_dropped_wire_log_count(*, reset: bool = False) -> int` (or positional-or-keyword `reset: bool = False` so
     both `get_dropped_wire_log_count(True)` and `get_dropped_wire_log_count(reset=True)` work): acquires
     `_wire_log_lock`, reads `_dropped_wire_log_count`, sets it to `0` if `reset` is `True`, and returns the count.
3. **Bounded Submission & Pruning in `dump_wire_transaction`:**
   - Preserve the early return `_completed_future()` when `not is_wire_logging_enabled() or not target_dir`.
   - Acquire `_wire_log_lock`:
     - Prune completed futures in-place to preserve the `_pending_wire_log_futures` set object identity:
       `_pending_wire_log_futures.difference_update([f for f in _pending_wire_log_futures if f.done()])`.
     - If `len(_pending_wire_log_futures) >= _wire_log_max_pending()`:
       - Increment `_dropped_wire_log_count += 1`.
       - Return `_completed_future()`.
     - Otherwise submit to `_get_wire_log_executor().submit(_write_transaction_sync, record, target_dir)` and add
       `future` to `_pending_wire_log_futures`.
   - Outside `_wire_log_lock`, attach `future.add_done_callback(_discard_pending_future)` and return `future`.
4. **Stay Within the 200-Line Budget (Without Touching `module_budgets.json`):**
   - Inline `_try_log_via_mitmproxy_ctx` into `log_telemetry` (saves ~7 lines while keeping McCabe complexity well
     below Ruff's `max-complexity = 10`).
   - Tighten `safe_turn_id`/`safe_flow_id`/`filepath` construction in `_write_transaction_sync` (saves ~3 lines).
   - Reuse `_completed_future()` in both disabled and overflow return paths (saves ~2 lines).
   - Verify `wc -l src/holon_coherence/proxy/wire_log.py` is `<= 200` after `uv run ruff format .`.
