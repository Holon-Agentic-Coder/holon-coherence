## Step 2: Fix SSE chunk fragmentation in `src/holon_coherence/proxy/steps/sse_tap.py`

### Step Intent & Git Integration

- **Sub-intent recommendation:** none (inline step)
- **Reasoning:** Core production bug fix addressing split multi-byte UTF-8 sequences, fragmented JSON SSE lines across TCP chunks, EOF buffer flushing, and dead self-assignment removal.
- **Step type:** implementation
- **Exploration level:** none
- **Git branch:** same feature branch

### Implementation Details

Edit `src/holon_coherence/proxy/steps/sse_tap.py` (currently 57 lines; target ~80–100 lines, strictly `<= 200` lines, zero docstrings, zero comments):

1. Import `codecs` from the standard library.
2. Inside `install_sse_tap(flow: Any, response: Any) -> None`:
   - Initialize per-flow state:
     - `flow.sse_chunks = []`
     - `flow.sse_bytes = 0`
     - `flow._sse_stream_state = {}`
     - `utf8_decoder = codecs.getincrementaldecoder("utf-8")(errors="replace")`
     - `line_buffer = ""`
     - `existing_stream = getattr(response, "stream", None)`
3. Extract a small helper `_record_sse_chunk(flow: Any, chunk: bytes) -> None` to keep `sse_stream_wrapper` clean and readable:
   - If `chunk`:
     - `flow.sse_bytes = getattr(flow, "sse_bytes", 0) + len(chunk)`
     - If `flow.sse_bytes <= _MAX_SSE_BUFFER_BYTES`: `flow.sse_chunks.append(chunk)`
4. Extract a small helper `_translate_bridged_text(flow: Any, text: str) -> bytes`:
   - If `not text`: return `b""`
   - Call `translate_openai_sse_chunk_to_gemini(text, stream_state=getattr(flow, "_sse_stream_state", None))` inside `try/except Exception as exc: logger.debug(...)` and return `translated.encode("utf-8")` (falling back to `text.encode("utf-8")` on exception so data is not silently lost).
   - Remove the dead `flow._sse_stream_state = getattr(flow, "_sse_stream_state", None)` self-assignment completely.
5. In `sse_stream_wrapper(chunk: bytes) -> bytes`:
   - Use `nonlocal line_buffer`.
   - When `chunk` is non-empty:
     - Update timing:
       - If `getattr(flow, "first_chunk_time", None) is None`: `flow.first_chunk_time = time.perf_counter()`
       - `flow.last_chunk_time = time.perf_counter()`
     - If `getattr(flow, "is_gemini_bridged", False)`:
       - `decoded = utf8_decoder.decode(chunk, final=False)`
       - `combined = line_buffer + decoded`
       - If `"\n" in combined`:
         - `complete_lines, line_buffer = combined.rsplit("\n", 1)`
         - `chunk = _translate_bridged_text(flow, complete_lines + "\n")`
       - Else:
         - `line_buffer = combined`
         - `chunk = b""`
     - Call `_record_sse_chunk(flow, chunk)` (which only appends when `chunk` is non-empty, avoiding empty `b""` entries in `flow.sse_chunks`).
   - When `chunk == b""` (EOF/final chunk):
     - If `getattr(flow, "is_gemini_bridged", False)`:
       - `flushed_text = line_buffer + utf8_decoder.decode(b"", final=True)`
       - `line_buffer = ""`
       - If `flushed_text`:
         - `chunk = _translate_bridged_text(flow, flushed_text)`
         - `_record_sse_chunk(flow, chunk)`
   - Finally:
     - If `callable(existing_stream)`: `return existing_stream(chunk)`
     - `return chunk`
6. Note on non-bridged SSE streams: raw bytes continue to pass through untouched and accumulate in `flow.sse_chunks`, which `load_exchange.py` joins with `b"".join(sse_chunks)` before decoding—preserving split UTF-8 byte sequences across chunks without altering passthrough latency or breaking existing passthrough tests.
