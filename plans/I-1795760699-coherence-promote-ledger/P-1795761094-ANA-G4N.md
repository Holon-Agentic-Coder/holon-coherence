  - Job-level `if: github.event_name != 'push' || !contains(github.event.head_commit.message, '[ledger-promote]')` to prevent self-trigger loops.
  - **Step 1 (`Checkout code`):** `uses: actions/checkout@v7` with `ref: main`, `fetch-depth: 0`, and `token: ${{ secrets.HOLON_LEDGER_BOT_TOKEN || github.token }}`.
  - **Step 2 (`CI Timing Gate (Start)`):** `uses: ./.github/actions/ci-timing-gate` with `phase: start`.

    - When `count == 0`, prints `::notice::HOLON_LEDGER_BOT_TOKEN is unset or empty; 0 pending ledger fragments under holon-knowledge/ledger/pending/.` and appends the 0-backlog status to `"$GITHUB_STEP_SUMMARY"`.
  - **Step 4 (`Promote pending ledger fragments`, `id: promote`):**
    - `env: HOLON_LEDGER_BOT_TOKEN: ${{ secrets.HOLON_LEDGER_BOT_TOKEN }}` and `FORCE_PROMOTE: ${{ github.event.inputs.force || 'false' }}`
    - `if: env.HOLON_LEDGER_BOT_TOKEN != ''`
    - Runs an inline `python3 - <<'PY'` script (no new files under `scripts/`):
      - Iterates over `("intents", "plans", "executions")`.
      - For each category, locates canonical `holon-knowledge/ledger/{category}.jsonl` and sorted `*.jsonl` files under `holon-knowledge/ledger/pending/{category}/`.
      - Reads existing canonical file bytes (if present) without altering them; builds a set of existing stripped lines for exact deduplication; tracks whether a leading `\n` is needed if the existing file is non-empty and does not end with `b"\n"`.
      - For each pending fragment file, parses each non-empty line with `json.loads` to validate JSONL integrity, skips lines already in the seen set, and buffers new lines as exact raw UTF-8 bytes plus `b"\n"`.
      - Opens the canonical file in `"ab"` (append-binary) mode only when new bytes exist so pre-existing canonical bytes remain strictly byte-identical.
      - Deletes each processed pending fragment file (`unlink()`).
      - Appends a summary table/line (files promoted, rows appended, duplicates skipped) to `GITHUB_STEP_SUMMARY` if set.
  - **Step 5 (`Verify ledger-only changes and commit`, `id: commit-push`):**
    - `env: HOLON_LEDGER_BOT_TOKEN: ${{ secrets.HOLON_LEDGER_BOT_TOKEN }}`
    - `if: env.HOLON_LEDGER_BOT_TOKEN != ''`
    - Runs `git status --porcelain --untracked-files=all` and fails with `::error::` + `exit 1` if any changed or untracked path does not start with `holon-knowledge/ledger/`.
    - If `holon-knowledge/ledger/` has changes: configures git `user.name` (`holon-ledger-bot`) and `user.email` (`holon-ledger-bot@users.noreply.github.com`), stages `git add -A holon-knowledge/ledger/`, commits with `chore(ledger): promote pending fragments [ledger-promote]`, and pushes to `origin HEAD:main`.
    - If no changes exist, prints `::notice::No pending ledger changes to promote.`
  - **Step 6 (`CI Timing Gate (Check <= 5 min)`):** `if: always()`, `uses: ./.github/actions/ci-timing-gate` with `phase: check` and `max-seconds: "300"`.
