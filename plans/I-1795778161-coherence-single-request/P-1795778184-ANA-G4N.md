### Implementation Details

- In `src/holon_coherence/payload_cleaner.py` (currently 158 lines, budget 200):
  - Import `Iterator` from `collections.abc`, `contextmanager` from `contextlib`, and `ContextVar` from `contextvars`.
  - Define module-level `_IN_PLACE_MUTATION: ContextVar[bool] = ContextVar("_in_place_mutation", default=False)`.
  - Define `@contextmanager def in_place_cleaning() -> Iterator[None]:` that sets `token = _IN_PLACE_MUTATION.set(True)`,
    yields inside `try:`, and resets `_IN_PLACE_MUTATION.reset(token)` in `finally:`.
  - Add a small helper `_serialized_length(payload: Any) -> int | None` that returns `len(json.dumps(payload))` or
    `None` on `Exception`.
  - Update `JSONContextCleaner.process_payload_with_stats` signature to:
    ```python
    def process_payload_with_stats(
        self,
        payload: dict[str, Any],
        provider: str = "anthropic",
        *,
        copy_payload: bool | None = None,
    ) -> CleaningResult:
    ```
  - Inside `process_payload_with_stats`:
    - Resolve `should_copy = (not _IN_PLACE_MUTATION.get()) if copy_payload is None else copy_payload`.
    - Measure `raw_chars = _serialized_length(payload)` BEFORE mutating `payload` in place so `chars_saved` remains
      exact when `should_copy` is `False`.
    - Set `cleaned_payload = copy.deepcopy(payload) if should_copy else payload`.
    - Run `self.pass_registry.run(...)` as before.
    - Compute `cleaned_chars = _serialized_length(cleaned_payload) if raw_chars is not None else None` and
      `chars_saved = max(0, raw_chars - cleaned_chars) if raw_chars is not None and cleaned_chars is not None else 0`.
  - Verify total file length stays `<= 200` lines (~176 lines), Ruff complexity stays well within limits
    (`max-args <= 5`, `C901 <= 10`), and zero docstrings / zero comments exist in the file.
